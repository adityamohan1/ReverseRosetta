ReverseRosetta

Excel in, optimized DNA out: human codon usage, restriction-site removal, splice-aware and repeat-aware refinement—built around CodonTransformer and optional SpliceFinder-style scoring.

Install

Python 3.11+ recommended.

$ git clone https://github.com/YOUR_USER/ReverseRosetta.git
$ cd ReverseRosetta
$ python -m venv .venv && source .venv/bin/activate
$ pip install -e ".[dev]"

Run

$ python -m reverserosetta \
    --input examples/ReverseRosettaTemplate.xlsx \
    --sheet Sheet1 \
    --output results/reverserosetta_output.xlsx \
    --host human

What it does

  • Reads amino acid sequences from a chosen Excel column (default: 4th column).
  • Generates human-optimized coding DNA with CodonTransformer.
  • Removes a fixed list of restriction sites via synonymous substitutions.
  • Reduces cryptic splice-like signals (heuristic or optional Keras SpliceFinder models).
  • Improves manufacturability scores (homopolymers, repeats, local complexity).
  • Exports Excel, CSV, and optional JSON audit logs.
